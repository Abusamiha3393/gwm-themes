# صحراء داش

عدادات وثيمات تُعرض فوق شاشة الوسائط في سيارات GWM (هافال وتانك)، وتقرأ بيانات السيارة الحية.

## التحميل والتحديث
كل تعديل يُرفع إلى `main` يبني ملف APK تلقائيًا. تجده في قسم **Releases** في المستودع.

بعد أول تثبيت، يتحقق التطبيق بنفسه من آخر إصدار هنا كل 6 ساعات. يظهر إشعار عند توفر تحديث، ويثبّته زر «ثبّت التحديث» في الإعدادات. يحتاج هذا أن يكون المستودع عامًا، وأن تسمح للتطبيق مرة واحدة بتثبيت التطبيقات.

## التثبيت على شاشة السيارة
1. ثبّت ملف APK.
2. افتح التطبيق، واضغط «اسمح بالعرض فوق التطبيقات».
3. اختياري: اسمح بقراءة الإشعارات حتى تظهر الأغنية الحالية.
4. اضغط «إظهار العدادات».

إذا ظهرت عبارة «لم يُعثر على خدمة السيارة»، فهذا يعني أن الشاشة لا تسمح للتطبيق بقراءة البيانات، وسيعرض بيانات تجريبية.

## الخصائص الحالية
- قراءة السرعة والدورات والوقود والمدى والحرارة والبطارية وزاوية المقود
- بيانات الطرق الوعرة: الميلان الأمامي والجانبي والبوصلة والارتفاع
- ستة ثيمات: «كثبان» (عدادات كلاسيكية)، «مسار» (الطرق الوعرة)، «نبض» (رقمي)، «رحلة» (الوقت والموسيقى)، «أفق» (قوس عريض)، «مضمار» (أضواء التبديل). كلها تتكيف مع ملء الشاشة ونصفها وثلثها
- مصمم العدادات مع معاينة حية: ألوان الإبرة والعلامات والأرقام واللوحات، وشكل الإبرة، والحجم والموضع، وتبديل العدادين، وحفظ التصاميم بأسماء
- صفحة معلومات السيارة والجهاز، مع أداة تشخيص تقرأ كل مفاتيح خدمة السيارة ويمكن نسخ نتيجتها أو مشاركتها
- تقسيم الشاشة: العدادات في جزء وتطبيق آخر (الخرائط مثلًا) في الباقي، أو تقسيم بين تطبيقين بنسبة تختارها
- النوافذ العائمة: عداد سرعة صغير قابل للسحب عند إخفاء العدادات، وفتح تطبيق في نافذة عائمة
- شكل العدادات: اللون، وأقصى سرعة ودورات، والكيلومتر أو الميل
- خلفية من صورك مع درجة تعتيم
- تنبيهات: الوقود المنخفض، وحرارة المحرك، والبطارية، والميلان الخطر
- عرض الأغنية الحالية مع أزرار التشغيل
- تعلّم أزرار المقود: زر لإظهار وإخفاء العرض، وزر للثيم التالي
- موضع العرض: ملء الشاشة، أو نصفها، أو ثلثها
- تشغيل تلقائي عند تشغيل السيارة
- وضع تجريبي للتجربة على أي جهاز
- تحديث تلقائي من إصدارات GitHub

## إضافة ثيم جديد
1. ضع ملف HTML في `app/src/main/assets/themes/`، وحمّل فيه `<script src="common.js"></script>` قبل سكربت الثيم. هذا الملف يضيف الخلفية والتنبيهات واللون (`var(--accent)`) تلقائيًا، ويوفر أدوات مثل `Sahra.speed(d)` و`Sahra.unit(d)`.
2. أضفه إلى القائمة في `Themes` داخل `Prefs.kt`.

يستقبل الثيم البيانات عبر:

```js
window.onSahraData = function (d) {
  // d.speed, d.rpm, d.gear, d.fuel, d.range, d.odometer, d.coolant,
  // d.outsideTemp, d.insideTemp, d.batteryVoltage, d.steering,
  // d.pitch, d.roll, d.compass, d.altitude, d.vin, d.demo,
  // d.media.{title, artist, playing, art}
  // d.style.{accent, speedMax, rpmMax, units, wallpaper, wallpaperDim, design}
  // d.alerts: [{id, text, level}], d.layout: full | left | right | left_third | right_third
};
window.onSahraKey = function (code) { /* أزرار المقود غير المخصّصة */ };
```

ويستطيع الثيم استدعاء: `SahraHost.close()`، و`SahraHost.nextTheme()`، و`SahraHost.media('toggle'|'next'|'prev')`، و`SahraHost.openApp(pkg)`، و`SahraHost.floatApp()`، و`SahraHost.openSettings()`.

تصميم المصمم يصل كمتغيرات CSS من `common.js`: `--needle` و`--tick` و`--num` و`--panel-c` و`--g-scale` و`--g-shift`، والصنف `swap` على `html`، وشكل الإبرة عبر `Sahra.needlePath(style)`.

القيم غير المتوفرة تصل `null`. افتح ملف الثيم في أي متصفح لمعاينته ببيانات وهمية (أضف `?lowfuel=1` لتجربة التنبيه، و`?units=mph` للأميال).

## التوقيع
يوقَّع التطبيق بالمفتاح `release.jks` الموجود في المستودع. الملف مشفّر بكلمة مرور قوية محفوظة فقط في أسرار GitHub باسم `KEYSTORE_PASSWORD`، لذلك لا يستطيع أحد توقيع نسخة باسمك حتى لو كان المستودع عامًا.

احتفظ بكلمة المرور في مكان آمن. إذا ضاعت، لن تقبل الشاشة التحديثات فوق النسخة المثبتة، وستضطر لحذف التطبيق وتثبيته من جديد بمفتاح جديد.
